# 관리자용 애니 감상 기록 가져오기 설계

## 목적

관리자가 다른 애니메이션 기록 서비스에서 복사한 여러 줄의 텍스트를 붙여넣어, 지정한 사용자의 이번 분기 감상 목록과 진도를 AnimeSquad로 가져온다. 저장 전 매칭 결과를 검토하며, 가져오기 작업은 스쿼드 피드에 노출하지 않는다.

## 권한과 대상 사용자

- 기능은 관리자만 사용할 수 있다.
- 프론트엔드 관리자 화면과 백엔드 API를 모두 관리자 권한으로 제한한다.
- 관리자는 고유한 이메일 주소로 대상 사용자를 검색한다.
- 이메일에 해당하는 사용자가 없으면 미리보기를 생성하지 않고 오류를 반환한다.
- 일반 로그인 사용자와 비로그인 사용자는 API를 직접 호출해도 접근할 수 없다.

## 입력 형식

한 줄에 한 작품을 입력한다. 각 줄의 마지막 `숫자 + 화`를 진도로, 그 앞부분 전체를 제목으로 해석한다.

```text
버려진 성녀의 이세계 밥 여행: 숨겨진 스킬로 캠핑카를 소환했습니다2화
투명한 밤을 달리는 너와, 눈에 보이지 않는 사랑을 했다.2화
월드 이즈 댄싱3화
```

처리 규칙은 다음과 같다.

- 앞뒤 공백과 빈 줄은 무시한다.
- 회차는 1 이상의 정수여야 한다.
- 제목이 비어 있거나 줄 끝이 `숫자 + 화` 형식이 아니면 해당 줄을 오류로 표시한다.
- 한 번에 최대 200줄을 허용한다.
- 같은 애니가 여러 줄에서 매칭되면 마지막 줄의 회차를 사용하고, 앞선 줄은 중복으로 표시한다.

## 제목 매칭

백엔드는 현재 캐시된 애니 데이터의 다음 필드를 사용한다.

- 한국어 제목
- 원어 제목
- 영어 제목
- 로마자 제목
- 검색 키워드

비교 전 대소문자, 공백, 일반적인 문장부호 차이를 정규화한다. 정규화된 제목이 정확히 일치하는 단일 작품만 자동 매칭한다. 일치 결과가 없거나 둘 이상이면 잘못된 작품을 선택하지 않고 미매칭으로 처리한다.

미리보기는 각 입력 줄에 대해 다음 상태 중 하나를 반환한다.

- `MATCHED`: 확실한 단일 작품과 매칭됨
- `UNMATCHED`: 일치하는 작품이 없거나 모호함
- `INVALID`: 입력 형식 또는 회차가 잘못됨
- `DUPLICATE`: 뒤의 동일 작품 입력으로 대체됨

미매칭 항목에는 원본 제목과 회차를 그대로 표시하고 “직접 검색해서 추가해주세요”라고 안내한다. 이 버전에서는 미리보기 화면 안에서 수동 매칭하거나 새 애니를 생성하지 않는다.

## 관리자 화면 흐름

1. 관리자가 대상 사용자 이메일과 원본 텍스트를 입력한다.
2. `미리보기`를 누른다.
3. 서버가 대상 사용자, 입력 형식, 제목 매칭을 검증한 결과를 반환한다.
4. `MATCHED` 행은 기본 선택 상태로 표시한다.
5. 관리자는 잘못됐다고 판단한 행의 선택을 해제할 수 있다.
6. `UNMATCHED`, `INVALID`, `DUPLICATE` 행은 선택할 수 없으며 사유를 표시한다.
7. 관리자가 `선택 항목 가져오기`를 누르면 선택된 결과만 일괄 저장한다.
8. 성공 후 생성·갱신·제외·미매칭 개수를 요약해 표시한다.

## API 구조

두 단계의 관리자 API를 제공한다.

### 미리보기

`POST /api/admin/watch-import/preview`

요청은 `email`, `text`를 받는다. 응답에는 대상 사용자의 최소 식별 정보와 줄별 `lineNumber`, `rawLine`, `title`, `progress`, `status`, `anime`, `message`를 포함한다.

### 저장

`POST /api/admin/watch-import/commit`

요청은 `targetUserId`와 관리자가 선택한 `animeId`, `progress` 목록을 받는다. 미리보기 결과 전체나 원문을 신뢰하지 않고 저장 시 다음을 다시 검증한다.

- 대상 사용자가 존재하는가
- 모든 애니가 존재하는가
- 회차가 1 이상인가
- 동일한 애니가 요청에 중복되지 않는가
- 항목 수가 200개 이하인가

미리보기와 저장 사이에 관리자가 선택을 변경할 수 있으므로 서버 상태를 저장하는 preview token은 도입하지 않는다.

## 저장 정책

- 신규 항목은 `WATCHING`, 입력된 진도로 생성한다.
- 기존 항목은 상태를 `WATCHING`, 진도를 입력된 값으로 덮어쓴다.
- 기존 진도가 더 높아도 가져온 값으로 덮어쓴다.
- 기존 시리즈 별점과 감상평은 유지한다.
- 회차별 별점과 감상평은 변경하지 않는다.
- 선택된 전체 항목은 하나의 트랜잭션에서 저장한다. 하나라도 실패하면 모두 롤백한다.

## 피드 억제

일반 사용자의 수동 기록 흐름은 기존 이벤트 기반 피드 생성을 유지한다. 가져오기 서비스는 일반 `WatchService.updateEntry`를 반복 호출하지 않고, 가져오기 전용 트랜잭션에서 `WatchEntry`를 생성·수정한다.

가져오기 전용 저장에서는 다음 이벤트를 발행하지 않는다.

- `AnimeAddedEvent`
- `WatchStatusChangedEvent`
- `ProgressUpdatedEvent`
- `WatchRatedEvent`

따라서 대상 사용자가 여러 스쿼드에 속해 있어도 가져온 항목은 스쿼드 피드에 추가되지 않는다.

## 오류 처리

- 인증되지 않음: `401`
- 관리자 아님: `403`
- 대상 이메일 또는 사용자 ID가 없음: `404`
- 빈 입력, 200줄 초과, 저장 요청 형식 오류: `400`
- 일부 행의 파싱·매칭 실패: 미리보기 자체는 성공하고 행별 상태로 반환
- 저장 도중 데이터 무결성 오류: 전체 트랜잭션 롤백 후 오류 반환

## 테스트 범위

### 백엔드

- 비로그인 및 일반 사용자 접근 차단
- 이메일 대상 사용자 조회
- 샘플 입력의 제목·회차 파싱
- 빈 줄, 잘못된 형식, 0화, 200줄 제한
- 제목 정규화와 단일 정확 매칭
- 미매칭 및 모호한 매칭
- 중복 작품에서 마지막 줄 선택
- 신규 `WATCHING` 기록 생성
- 기존 상태·진도 덮어쓰기
- 기존 별점·감상평 유지
- 피드 활동 미생성
- 저장 요청 재검증 및 전체 롤백

### 프론트엔드

- 관리자만 메뉴와 페이지 접근
- 이메일·텍스트 입력 및 미리보기
- 상태별 행 표시와 선택 가능 여부
- 선택 해제 및 저장 요청
- 성공 요약과 API 오류 표시

## 범위 밖 항목

- 일반 사용자의 직접 가져오기
- CSV, JSON 등 다른 입력 포맷
- 미리보기 안에서의 수동 애니 매칭
- 캐시에 없는 애니를 AniList에서 자동 생성
- 별점, 감상평, 회차별 리뷰 가져오기
- 가져오기 이력 및 되돌리기 UI

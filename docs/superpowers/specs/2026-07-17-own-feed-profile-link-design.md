# 내 피드 활동 프로필 링크 수정 설계

## 문제

메인피드와 스쿼드피드의 공용 `Timeline`은 모든 작성자 프로필 링크를 `/users/{id}`로 만든다. 이 때문에 로그인 사용자가 자신의 프로필 사진이나 이름을 눌러도 타인용 프로필 화면이 열리고, 프로필 수정과 로그아웃 기능이 보이지 않는다.

## 설계

`Timeline`에 현재 로그인 사용자 ID를 선택적으로 전달한다. 활동 작성자 ID가 현재 사용자 ID와 같으면 프로필 사진과 작성자 이름의 링크를 모두 `/profile`로 만들고, 다르면 기존처럼 `/users/{id}`를 사용한다.

메인피드는 이미 조회한 `me.id`를 `Dashboard`를 통해 `Timeline`에 전달한다. 스쿼드피드는 기존 `me` 상태의 ID를 전달한다. 현재 사용자 정보가 아직 없거나 조회에 실패한 경우에는 기존 타인 프로필 링크를 유지한다.

백엔드 API와 타인 프로필 페이지는 변경하지 않는다.

## 검증

- 현재 사용자와 활동 작성자 ID가 같으면 프로필 사진과 이름이 모두 `/profile`을 가리킨다.
- ID가 다르면 두 링크 모두 `/users/{작성자 ID}`를 가리킨다.
- 기존 프런트엔드 테스트와 빌드가 통과한다.

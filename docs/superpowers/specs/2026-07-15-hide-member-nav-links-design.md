# 비로그인 Navbar 회원 메뉴 숨김 설계

## 목적

로그인하지 않은 방문자에게 회원 전용인 `내 목록`과 `스쿼드` 메뉴를 노출하지 않는다.

## 동작

- 비로그인 상태와 로그인 확인 중에는 `탐색`만 표시한다.
- 로그인 확인에 성공하면 `내 목록`과 `스쿼드`를 추가한다.
- 관리자 로그인 사용자는 기존처럼 `관리자` 메뉴도 추가한다.
- 검색창, 로고, 프로필 표시와 OAuth·온보딩 흐름은 변경하지 않는다.
- 데스크톱과 모바일 드로어는 동일한 `links` 배열을 사용해 같은 메뉴를 표시한다.

## 구현

`NavBar.tsx`의 링크 정의를 공개 링크와 회원 링크로 나눈다. 렌더링 직전에 `me` 존재 여부로 배열을 조합하고, `me.isAdmin`일 때만 관리자 링크를 덧붙인다. 별도의 인증 요청이나 CSS 숨김 로직은 추가하지 않는다.

## 검증

- `me`가 없을 때 계산된 링크에 `내 목록`, `스쿼드`, `관리자`가 없음을 확인한다.
- 로그인 사용자 링크에 `내 목록`과 `스쿼드`가 있고, 관리자에게만 `관리자`가 있음을 확인한다.
- TypeScript 검사와 ESLint를 실행한다.

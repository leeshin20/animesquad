# Chrome Extension — 엔딩 감지 기반 시청 기록

## 개요

AnimeSquad Chrome 확장 프로그램의 시청 완료 판단 기준을 기존의 "페이지에 10분 이상 체류"에서 실제 재생 상태에 가까운 기준으로 변경한다.

기록 후보는 다음 우선순위로 생성한다.

1. 스트리밍 사이트의 엔딩·크레딧 건너뛰기 버튼이 노출됨
2. 본편 영상이 90% 지점에 도달한 뒤 실제 재생 시간이 30초 누적됨
3. 본편 영상의 `ended` 이벤트가 발생함

기록 후보가 생성되면 기존 동작과 동일하게 애니 제목과 회차를 파싱하고 기록 팝업을 연다. 사용자 확인 없이 서버에 자동 저장하지 않는다.

## 대상 사이트

- Crunchyroll
- Netflix
- 라프텔

추가 사이트는 최대 5개 안팎을 예상하며, 공통 감지기를 복잡하게 만들지 않고 사이트 전용 감지기를 추가하는 방식으로 지원한다.

## 아키텍처

### Content Script

현재 `chrome-extension/content/index.js`가 담당하는 10분 타이머를 제거하고 다음 세 구성 요소로 역할을 나눈다.

#### 사이트별 엔딩 감지기

각 사이트 감지기는 "엔딩 UI가 현재 사용자에게 노출되었는가"만 판단한다.

- Crunchyroll: 크레딧 건너뛰기 버튼의 `aria-hidden`이 `false`로 바뀌는 것을 감지한다.
- Netflix: 크레딧 건너뛰기 또는 다음 화 UI의 DOM 노출 상태를 감지한다.
- 라프텔: 엔딩 건너뛰기 또는 다음 화 UI의 DOM 노출 상태를 감지한다.
- 사이트별 DOM 차이는 개별 감지기 내부에만 둔다.

페이지가 SPA 방식으로 UI를 갱신하므로 `MutationObserver`로 요소 추가와 관련 속성 변경을 관찰한다. Crunchyroll 감지를 위해 `aria-hidden` 속성 변경도 관찰 대상에 포함한다.

#### 영상 진행률 보조 감지기

사이트별 엔딩 UI가 없거나 감지 규칙이 일시적으로 맞지 않을 때를 대비한 보조 신호다. 버튼 감지와 항상 병렬로 실행하며 먼저 발생한 기록 후보만 사용한다.

- 화면에 보이는 재생 가능한 `<video>` 중 가장 큰 요소를 본편 후보로 선택한다.
- `duration`이 유한하고 5분 이상인 영상만 검사해 짧은 광고·미리보기를 제외한다.
- `timeupdate`, `durationchange`, `play`, `pause`, `seeking`, `seeked`, `ended` 이벤트를 이용한다.
- `currentTime / duration >= 0.9`가 된 시점부터 실제 재생 시간을 누적한다.
- 재생 중이며 탐색 중이 아닌 시간만 누적한다.
- 90% 이후 실제 재생 시간이 총 30초 누적되면 기록 후보를 생성한다.
- 일시정지와 버퍼링은 누적을 멈추지만 이미 누적된 실제 재생 시간은 유지한다.
- 90% 미만으로 탐색하거나 새 에피소드로 전환하면 누적 시간을 초기화한다.
- 사용자가 탐색바를 90% 이후로 옮긴 것만으로는 기록 후보를 생성하지 않는다.
- `ended` 이벤트는 30초 누적과 별개로 즉시 기록 후보를 생성한다.

#### 기록 후보 조정기

엔딩 버튼, 90% 보조 기준, `ended` 이벤트가 동시에 발생해도 한 번만 처리한다.

- 제목·회차·현재 URL을 기반으로 에피소드 키를 만든다.
- 에피소드 키별로 기록 후보 전송 여부를 메모리에 보관한다.
- 후보가 처음 생성될 때만 기존 `WATCHED` 메시지를 Service Worker에 전송한다.
- 같은 페이지에서 반복되는 DOM 변경과 영상 이벤트는 무시한다.
- URL 또는 파싱된 애니·회차가 바뀌면 새 에피소드 상태로 초기화한다.
- 제목이나 회차를 파싱할 수 없더라도 기존 수동 검색 흐름을 사용할 수 있도록 가능한 파싱 결과를 전송한다.

### Service Worker와 Popup

기존 `WATCHED` 메시지 처리와 기록 팝업 흐름을 그대로 사용한다.

- Service Worker는 애니 검색 결과를 `pending`에 저장한다.
- 팝업을 열 수 있으면 즉시 열고, 불가능하면 기존처럼 배지를 표시한다.
- 실제 워치리스트 추가와 회차 기록은 사용자가 팝업의 `기록하기`를 눌렀을 때만 수행한다.
- 팝업의 "10분 이상 보면" 안내 문구를 엔딩 감지 기준에 맞게 수정한다.

## 상태 전환

1. 페이지 진입 또는 SPA 회차 전환 시 제목과 회차를 파싱한다.
2. 사이트별 엔딩 감지기와 영상 진행률 감지기를 시작한다.
3. 엔딩 버튼이 노출되면 즉시 기록 후보를 만든다.
4. 이와 병렬로 영상 90% 이후 30초 실제 재생 누적 또는 `ended` 이벤트로 기록 후보를 만든다.
5. 조정기가 같은 에피소드의 첫 후보만 `WATCHED` 메시지로 전송한다.
6. URL이나 파싱 결과가 바뀌면 이전 감지기를 정리하고 새 에피소드 감지를 시작한다.

## 예외 처리

- 사이트 UI 변경으로 버튼을 찾지 못하면 90% 보조 기준이 동작한다.
- `<video>` 요소를 찾지 못하면 버튼 감지만 유지한다.
- 5분 미만 영상과 화면에서 보이지 않는 영상은 본편 후보에서 제외한다.
- 영상이 일시정지되거나 버퍼링되는 동안에는 30초를 누적하지 않는다.
- 영상 탐색 중에는 재생 시간을 누적하지 않는다.
- 페이지 이탈만으로는 시청 완료로 판단하지 않는다.
- 감지기 내부 오류가 다른 사이트 감지나 기존 팝업 기능을 중단시키지 않도록 사이트별 감지 실패를 격리한다.

## 테스트

### 단위 테스트

- Crunchyroll 버튼의 `aria-hidden`이 `true`일 때 전송하지 않는다.
- `aria-hidden`이 `false`로 바뀌면 한 번만 `WATCHED`를 전송한다.
- 90% 이전에는 실제 재생 시간이 길어도 전송하지 않는다.
- 90% 이후 실제 재생 시간이 총 30초 누적되면 한 번만 전송한다.
- 90% 이후로 탐색만 한 경우 전송하지 않는다.
- 90% 이후 일시정지된 시간은 누적하지 않는다.
- 일시정지 후 재생을 계속하면 기존 누적 시간부터 이어서 계산한다.
- 90% 미만으로 탐색하면 누적 시간을 초기화한다.
- `ended` 발생 시 즉시 한 번만 전송한다.
- 엔딩 버튼과 90% 조건이 연속으로 발생해도 중복 전송하지 않는다.
- URL 또는 회차가 바뀌면 새 에피소드에서 다시 전송할 수 있다.

### 수동 확인

- Crunchyroll에서 크레딧 건너뛰기 버튼이 나타날 때 팝업 또는 배지가 한 번 표시된다.
- Netflix와 라프텔에서 사이트별 엔딩 UI가 나타날 때 동일하게 동작한다.
- 버튼이 없는 영상은 90% 이후 30초 재생하거나 영상이 끝났을 때 동작한다.
- 탐색바를 끝부분으로 옮긴 직후에는 동작하지 않는다.
- 다음 화 자동재생 시 새 회차를 별도로 감지한다.

## 범위 제외

- 이미지 인식이나 OCR로 버튼을 찾는 기능
- 사용자의 확인 없이 서버에 시청 기록을 자동 저장하는 기능
- 대상 세 사이트 외의 신규 사이트 지원
- 스트리밍 사이트의 UI 변경을 원격 설정으로 즉시 배포하는 기능

# Chrome Extension — 라프텔 엔딩 버튼 감지 검증

## 문제

현재 라프텔 감지기는 `엔딩 건너뛰기`, `크레딧 건너뛰기`, `다음 화`, `다음화`를
찾지만 실제 라프텔 플레이어는 `엔딩 스킵`과 `바로 재생`을 표시한다. 자동 엔딩
스킵이 활성화되면 기존 감지 문구가 나타나지 않고 영상 교체 과정에서 `ended`나
90% 보조 기준도 충족되지 않을 수 있어 기록 팝업이 열리지 않는다.

## 목표

- 라프텔에서 표시된 `엔딩 스킵` 또는 `바로 재생` 버튼을 감지하면 기록 팝업을 연다.
- 라프텔의 기존 네 문구는 더 이상 엔딩 신호로 취급하지 않는다.
- DOM 변경 후 50ms 병합 시간과 1초 보조 검사는 유지한다.
- 90% 이후 실제 재생 30초와 `ended` 보조 기준은 유지한다.

## 감지 규칙

라프텔의 표시된 `button`, `[role="button"]`, `[aria-label]` 요소에서 접근 가능한
문구와 텍스트를 공백 정리한 뒤 다음 문구와 정확히 일치할 때만 엔딩 신호로 본다.

- `엔딩 스킵`
- `바로 재생`

부분 일치는 사용하지 않는다. 예를 들어 `바로 재생 설정`은 감지하지 않는다.
숨겨졌거나 `aria-hidden="true"`인 요소, 크기가 없는 요소는 기존처럼 무시한다.

## 유지되는 동작

- 같은 URL·작품·회차에서는 팝업 요청을 한 번만 전송한다.
- 실제 서버 기록은 사용자가 팝업에서 `기록하기`를 눌러야 수행한다.
- 화면에 보이는 5분 이상 본편 영상이 90% 이후 실제로 30초 재생되거나 `ended`
  이벤트가 발생하면 버튼과 별개로 기록 후보를 만든다.

## 테스트

- 표시된 `엔딩 스킵`을 라프텔 엔딩 신호로 감지한다.
- 표시된 `바로 재생`을 라프텔 엔딩 신호로 감지한다.
- 기존 `엔딩 건너뛰기`, `크레딧 건너뛰기`, `다음 화`, `다음화`는 감지하지 않는다.
- `바로 재생 설정`처럼 문구가 추가된 요소는 감지하지 않는다.
- 숨겨진 `엔딩 스킵` 또는 `바로 재생`은 감지하지 않는다.
- Netflix와 Crunchyroll의 현재 감지 규칙은 변하지 않는다.
- 전체 확장 프로그램 테스트를 실행한다.

## 범위 제외

- 라프텔 제목·회차 파싱 변경
- 라프텔 재생 URL 제한
- Netflix 또는 Crunchyroll 감지 변경
- 50ms 병합 시간과 영상 진행률 기준 변경

# AnimeSquad 브랜드 컬러·로고·PWA 아이콘 설계

- 작성일: 2026-07-18
- 상태: 사용자 승인 완료
- 범위: 브랜드 컬러 토큰, 로고 심볼, navbar 브랜드 표시, 웹·PWA 아이콘

## 1. 목표

AnimeSquad의 기존 흰색·중립 회색 중심 UI와 미니멀한 인상을 유지하면서, 활기차고 친근한 애니 커뮤니티라는 성격을 초록색 브랜드 포인트로 표현한다.

브랜드 심볼은 대문자 `A`와 삼각형을 결합한 형태로 만든다. navbar에서는 심볼 옆에 실제 텍스트 `AnimeSquad`를 표시하고, 같은 심볼을 favicon과 PWA 설치 아이콘에 일관되게 사용한다.

## 2. 브랜드 인상

- 미니멀하고 현대적이다.
- 활기차지만 장난스럽거나 복잡하지 않다.
- 혼자 기록하는 도구보다 함께 보는 팀과 커뮤니티의 느낌을 준다.
- 작은 앱 아이콘과 navbar에서도 즉시 식별된다.

## 3. 컬러 시스템

| 역할 | 값 | 용도 |
|---|---|---|
| Brand Bright | `#22C55E` | 로고의 주 면, 앱 아이콘 배경, 비텍스트 장식 |
| Brand Strong | `#15803D` | 주요 버튼 배경, 강조 텍스트, 로고의 접힌 면 |
| Brand Soft | `#DCFCE7` | 선택 상태 배경, 배지, 연한 강조 영역 |
| Brand Light | `#4ADE80` | 로고의 보조 면과 제한적인 하이라이트 |

기존 neutral 팔레트와 흰색 배경은 유지한다. 모든 요소를 초록색으로 바꾸지 않고, 브랜드 식별과 상호작용 상태에만 초록색을 사용한다.

`#22C55E` 위의 흰색 본문 글자는 일반 텍스트 대비가 부족하므로 주요 버튼 배경에는 `#15803D`를 사용한다. `#22C55E`는 로고, 아이콘 배경, 비텍스트 강조에 집중한다.

## 4. 로고 심볼

### 4.1 형태

플랫 투톤을 기반으로 한 리본형 대문자 `A`를 사용한다.

- 위로 모이는 두 사선은 대문자 `A`이자 삼각형의 외곽을 만든다.
- 하단 가로 면은 `A`의 가로획이면서 접힌 리본처럼 보인다.
- 밝고 진한 초록 면의 차이로 두 조각이 맞물린 구조를 표현한다.
- 그라디언트, 외곽선, 텍스처, 그림자는 원본 심볼에 포함하지 않는다.
- 작은 크기에서 뭉치지 않도록 면 수와 내부 디테일을 최소화한다.

### 4.2 색상 변형

- 기본형: 주 면 `#22C55E`, 접힌 면 `#15803D`, 작은 끝 면 `#4ADE80`로 구성한다. 주 면과 접힌 면의 투톤이 구조를 만들고, 끝 면의 밝은 색은 리본 방향을 구분하는 보조 강조로만 사용한다.
- 앱 아이콘형: `#22C55E` 배경 위 흰색 주 면과 `#DCFCE7` 보조 면
- 단색형: 색상 표현이 제한되는 환경을 위한 한 가지 색의 실루엣

### 4.3 워드마크 결합

별도의 래스터 워드마크 이미지는 만들지 않는다. navbar에서는 심볼과 Geist SemiBold 실제 텍스트를 조합한다.

- 표시 문구: `AnimeSquad`
- 심볼 표시 크기: 28px
- 심볼과 텍스트 간격: 9px
- 텍스트는 현재 navbar의 크기와 tracking을 유지해 기존 레이아웃 변화를 최소화한다.

## 5. 산출물

벡터 원본에서 필요한 래스터 아이콘을 생성한다.

| 산출물 | 형식·크기 | 용도 |
|---|---|---|
| 기본 심볼 | SVG | navbar와 재사용 가능한 원본 |
| 단색 심볼 | SVG | 단색 환경과 대체 표현 |
| favicon | ICO, 16×16과 32×32 프레임 포함 | 브라우저 탭 |
| Apple Touch Icon | PNG 180×180 | iOS 홈 화면 |
| PWA 아이콘 | PNG 192×192, 512×512 | 설치 앱 아이콘 |
| PWA maskable 아이콘 | PNG 192×192, 512×512 | Android 적응형 아이콘 |

Maskable 아이콘은 플랫폼 마스크에 의해 심볼이 잘리지 않도록 핵심 도형을 중앙 안전 영역 안에 둔다. 모든 래스터 파일은 동일한 SVG 기하를 기반으로 생성해 크기별 형태 차이를 방지한다.

## 6. 서비스 적용

### 6.1 Navbar

현재 텍스트 링크 자리에 심볼과 `AnimeSquad` 텍스트를 나란히 배치한다. 데스크톱 navbar와 모바일 드로어 헤더에서 같은 조합을 사용한다. 로고 링크의 목적지와 접근 가능한 이름은 기존처럼 홈으로 유지한다.

### 6.2 PWA와 메타데이터

Next.js App Router가 제공하는 metadata와 manifest 경로를 사용해 다음 항목을 선언한다.

- 앱 이름과 짧은 이름: `AnimeSquad`
- theme color: `#22C55E`
- background color: `#FFFFFF`
- display: `standalone`
- 일반 PWA 아이콘과 maskable 아이콘
- Apple Touch Icon과 favicon

### 6.3 UI 포인트 컬러

기존 neutral UI를 기반으로 다음 역할부터 브랜드 컬러를 적용한다.

- 주요 CTA와 확인 동작: `#15803D` 배경, 흰색 텍스트
- 선택된 navigation, chip, tab 등: `#DCFCE7` 배경, `#15803D` 텍스트
- keyboard focus ring과 제한적인 장식: brand green 계열
- 위험, 경고, 오류 상태: 기존 rose/amber 계열 유지

일반 본문, 테두리, 보조 텍스트까지 초록색으로 바꾸지 않는다.

## 7. 구현 경계

- 이미지 생성 모델로 래스터 로고를 생성하지 않는다. 기하 형태를 결정론적인 SVG로 제작한다.
- 기존 페이지 레이아웃과 typography를 재설계하지 않는다.
- 서비스 전체의 모든 neutral 버튼을 한 번에 브랜드 버튼으로 바꾸지 않는다. 주요 CTA와 명확한 선택 상태만 범위에 포함한다.
- 다크 모드, 애니메이션 로고, 별도 마케팅용 워드마크는 이번 범위에 포함하지 않는다.

## 8. 검증 기준

- SVG가 배율과 관계없이 선명하고 투명 배경에서 올바르게 표시된다.
- navbar의 28px 크기와 favicon 크기에서도 `A` 실루엣과 접힌 면이 식별된다.
- PWA 일반 아이콘과 maskable 아이콘이 192px 및 512px로 존재하고 manifest에서 올바르게 참조된다.
- maskable 아이콘을 원형·둥근 사각형 등 일반적인 마스크로 잘라도 핵심 심볼이 손상되지 않는다.
- 설치된 앱, 브라우저 탭, iOS 홈 화면에서 동일한 브랜드가 보인다.
- 주요 버튼과 선택 상태의 텍스트 대비가 WCAG AA 수준을 충족한다.
- 데스크톱 navbar와 모바일 드로어에서 로고 때문에 overflow나 정렬 회귀가 생기지 않는다.
- 프론트엔드 테스트, 타입 검사, 프로덕션 빌드가 통과한다.

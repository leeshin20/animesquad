# Chrome Extension — 아이콘 클릭 기반 수동 인식

## 개요

AnimeSquad 확장 프로그램의 엔딩 버튼, 영상 진행률, `ended` 이벤트 기반 자동 감지를
중단한다. 사용자가 확장 프로그램 아이콘을 눌렀을 때만 현재 활성 탭에서 작품명과
회차를 인식하고, 기존 기록 팝업에 결과를 표시한다. 서버 기록은 사용자가 팝업의
`기록하기`를 눌렀을 때만 수행한다.

## 사용자 흐름

1. 사용자가 Netflix, 라프텔 또는 Crunchyroll의 시청 페이지에서 확장 아이콘을 누른다.
2. 팝업이 로그인 상태를 확인한다.
3. 로그인 상태라면 팝업이 현재 활성 탭의 콘텐츠 스크립트에 인식 요청을 보낸다.
4. 콘텐츠 스크립트는 요청을 받은 순간 기존 사이트별 파서로 작품명과 회차를 읽어 응답한다.
5. 팝업은 작품을 검색하고 기존 회차·평점·한줄평 입력 화면을 표시한다.
6. 사용자가 `기록하기`를 누르면 기존 API 흐름으로 기록한다.

지원 사이트가 아니거나 콘텐츠 스크립트에 연결할 수 없거나 제목을 파싱할 수 없으면
자동으로 기록 화면을 만들지 않고, 지원 사이트의 재생 화면에서 다시 아이콘을 누르라는
안내를 표시한다. 작품명은 인식했지만 AnimeSquad 검색 결과가 없으면 기존 수동 작품
검색 UI를 표시한다.

## 구성 요소

### Content Script

`content/index.js`는 자동 관찰과 영상 이벤트를 모두 제거하고 메시지 응답 역할만 맡는다.

- `DETECT_CURRENT` 메시지만 처리한다.
- 메시지를 받는 시점에 `asqParsePage(location.hostname, document.title, document)`를 호출한다.
- 결과를 `{ parsed }` 형태로 동기 응답한다.
- `MutationObserver`, `setInterval`, 영상 이벤트, 엔딩 버튼 검사, `WATCHED` 전송은 사용하지 않는다.

사이트별 제목·회차 파싱은 기존 `content/parsers.js`를 유지한다. 자동 감지 전용
`content/watch-detectors.js`와 관련 테스트는 제거한다. 자동 감지 코드는 Git 기록에서
나중에 필요한 부분만 다시 가져올 수 있다.

### Popup

팝업은 로그인 확인 후 현재 창의 활성 탭 ID를 조회하고 `DETECT_CURRENT` 메시지를 보낸다.
탭의 URL이나 제목을 직접 읽지 않으므로 광범위한 `tabs` 권한은 추가하지 않는다.

- 응답에 유효한 파싱 결과가 있으면 `searchAnime(animeName)`을 호출한다.
- 검색 성공 여부와 관계없이 기존 `loadRecord()` 흐름을 사용한다.
- 메시지 연결 실패와 `null` 파싱 결과는 빈 안내 화면으로 처리한다.
- 팝업을 열 때마다 현재 탭을 새로 인식하며 이전 감지 결과를 재사용하지 않는다.
- 검색 API가 실패하면 빈 검색 결과로 처리해 수동 작품 검색 UI를 제공한다.

### Background와 Storage

자동 `WATCHED` 메시지, pending 저장, `chrome.action.openPopup()` 처리는 모두 제거한다.
따라서 자동 감지 전용 Service Worker와 테스트를 제거하고 매니페스트의 background 선언도
제거한다. pending을 사용하지 않으므로 팝업의 storage 접근과 매니페스트의 `storage`
권한도 제거한다.

### Manifest와 패키지

- 콘텐츠 스크립트는 `content/parsers.js`, `content/index.js`만 로드한다.
- 기존 세 지원 사이트의 `matches` 범위는 유지한다.
- 확장 프로그램 버전을 `1.0.2`로 올린다.
- 검증된 운영 파일만 포함하는 루트 매니페스트 ZIP을 다시 생성한다.

## 오류 처리

- 로그인 확인 실패: 기존 로그인 안내를 표시한다.
- 활성 탭 없음: 지원 페이지 안내를 표시한다.
- 콘텐츠 스크립트 연결 실패: 지원 페이지 안내를 표시한다.
- 파싱 결과 없음 또는 서비스명뿐인 제목: 지원 페이지 안내를 표시한다.
- 작품 검색 API 실패 또는 검색 결과 없음: 감지한 작품명을 채운 수동 검색 UI를 표시한다.
- 기록 API 실패: 기존 재시도 안내를 유지한다.

## 테스트

- 콘텐츠 스크립트는 로드만으로 `WATCHED`를 보내지 않는다.
- `DETECT_CURRENT` 요청 시 현재 페이지를 파싱해 응답한다.
- 다른 메시지는 무시한다.
- 팝업은 로그인 후 활성 탭에 `DETECT_CURRENT`를 보낸다.
- 유효한 응답은 기존 기록 화면과 검색 흐름으로 연결된다.
- 연결 실패나 `null` 응답은 빈 안내 화면을 표시한다.
- 팝업을 다시 열면 저장된 이전 결과 대신 현재 탭을 다시 조회한다.
- pending 저장·조회·삭제와 자동 팝업 호출이 운영 코드에서 제거된다.
- 매니페스트에서 background, storage 권한, 자동 감지 스크립트를 제거하고 버전 `1.0.2`를 확인한다.
- 전체 확장 프로그램 테스트와 배포 ZIP 구조·내용을 검증한다.

## 범위 제외

- 사이트별 파싱 규칙 개선
- 자동 엔딩 버튼 감지
- 영상 90% 또는 `ended` 감지
- 자동 팝업과 배지 알림
- 사용자의 확인 없는 서버 자동 저장
